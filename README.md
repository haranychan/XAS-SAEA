# XAS-SAEA
[eXplainable Adaptive Switching-based Surrogate-assisted Evolutionary Algorithm](https://ieeexplore.ieee.org/document/11727241/)

- This is open-source code for XAS-SAEA implemented in MATLAB.

- All code is original and implemented to run on [PlatEMO](https://github.com/BIMK/PlatEMO/releases).


## How to run

  1. Download all the files of XAS-SAEA and [PlatEMO](https://github.com/BIMK/PlatEMO/releases).
  
  1. Add the XAS-SAEA directory from this repository to the `Algorithms/Single-objective optimization` directory.

  1. Run `platemo.m` and select XAS-SAEA. See the documents of PlatEMO for more details.
